Class Methods

Standalone Functions

Auto-Detection

Phase 2 — Resilience

Crash Recovery

On workflow start, check storage for partial progress (incomplete step sequence). Resume from first uncompleted step rather than starting over. Detect stale/incomplete state and clean up.

Step Timeouts

Each step can have an optional timeout. If a step exceeds its timeout, it is retried per the retry policy or the workflow fails.

Workflow-Level Timeout

An overall timeout for the entire workflow. If exceeded, the workflow is aborted and state is cleaned up.

Phase 3 — Dev Experience

Lifecycle Hooks

onStepStart, onStepComplete, onStepRetry, onStepFail, onWorkflowComplete, onWorkflowFail. Passed via @workflow({ hooks: { ... } }).

Progress Reporting

Emit progress events with step counts, estimated completion, and elapsed time for long-running workflows.

Phase 4 — Advanced

Pluggable Storage

Interface: { get, set, delete, has, clear }. Built-in adapters: IndexedDB, in-memory, localStorage, OPFS. Custom adapters for Electron, Tauri, Node.js.

Sub-Workflows

Allow one workflow to call another as a sub-workflow. Sub-workflow results are persisted and recoverable independently.

Serialization Hooks

Register custom serializers for user-defined types via registerSerializer(typeTag, { serialize, deserialize }).

Phase 5 — Tooling

Workflow Inspector

A browser extension or embedded panel showing active workflows, current step, step history with timing, retries, errors, and stored state inspection.

Logging & Telemetry

Structured logging for each step execution. Optional integration with observability backends.

Testing Utilities

Helpers to simulate crashes, retries, and step failures in tests. Mock storage backend for deterministic testing.

Phase 6 — Hardening

Storage Quota

Monitor storage usage and evict old/complete workflow state. Configurable max storage per workflow.

Error Classification

Distinguish retryable errors (network, timeout) from fatal errors (invalid input, permission). Allow custom error classifiers.

Serialization Safety

Deep-check step inputs and outputs for serializability. Provide hooks for custom serialization of complex types.

Phase 7 — Ecosystem

Framework Integrations

Optional adapters for React, Vue, Svelte, Angular providing reactive state binding and progress display. Electron / Tauri adapters for file-system-backed storage.

Workflow Visualization

Generate a static graph of workflow steps from source code analysis. Runtime visualization of active workflows.

CLI Scaffolding

npx create-durable-workflow to scaffold a new project. Code generation for common workflow patterns.
